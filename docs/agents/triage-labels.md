# Triage Labels

The canonical roles and the local status strings are identical:

| Role | Status string | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is pending. |
| `needs-info` | `needs-info` | Reporter input is required. |
| `ready-for-agent` | `ready-for-agent` | The task is specified for implementation. |
| `ready-for-human` | `ready-for-human` | Human implementation is required. |
| `wontfix` | `wontfix` | The task will not be actioned. |

Use the status string corresponding to the role named by a skill.
