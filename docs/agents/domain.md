# Domain Docs

This is a single-context repository. Before exploring or changing a domain concept, read the root `CONTEXT.md` and relevant ADRs in `docs/adr/` when they exist. Their absence is expected: continue without creating placeholders. Create or update them when domain terminology or an architectural decision is actually resolved.

Use the vocabulary in `CONTEXT.md` in tickets, tests, and proposals. If a proposed change conflicts with an ADR, name the conflict and explain why the decision should be revisited.
